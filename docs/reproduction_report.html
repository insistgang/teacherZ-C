Section 0

报告定位

这里的复现评估不是声称完整复现 15 篇论文。真实论文级复现往往需要 MRA、radio interferometry visibilities、sphere wavelet stack、proximal MCMC diagnostics 或 large-scale benchmark。当前目标是建立一个可运行、可检查、可展示的 minimal reproducible experiment 系统。

每个实验固定随机种子，结果写入 reproduce/results/repro_results.json 和 reproduce/results/repro_results.csv，页面展示的 completed 指标来自本地脚本实际运行结果。
